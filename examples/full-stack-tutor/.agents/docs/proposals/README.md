# Workflow Proposals

Proposals preserve reusable workflow improvements and human decisions under `.agents/docs/proposals/` without allowing autonomous policy drift. Legacy `suggestions/` records remain readable; do not duplicate or discard their decisions.

Use `NNNN-kebab-case-title.md` and one of these statuses: `proposed`, `accepted`, `applied`, `rejected`, or `superseded`. Only a human decision can move a proposal beyond `proposed`. Record the decision owner, date, rationale, canonical target, validation, and application evidence.
