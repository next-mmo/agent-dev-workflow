## Product Requirement

Maintain small, runnable examples that demonstrate Agent Workflow Scrum in ordinary products. The first example is a vanilla browser served by a minimal Express application.

## Acceptance Criteria

- [x] The example has no frontend framework or build step.

- [x] The example has a reproducible package lock and an HTTP integration test.
- [x] The example README contains only install, test, run, and open steps.
